# 화면 디자인 기준

화면 구현 시 `5.StoryBoardUI설계서_Backpack_v1.1.pptx`를 기준으로 확인합니다.
기존 `Backpack_화면시안_v2_블루.pdf`와 색상이 다른 경우 PPT v1.1의 코랄 테마를 우선합니다.
원본 자료는 별도로 공유받으며, 개인 PC 경로는 저장하지 않습니다.

## 색상 (PPT 5쪽, BC-001)

| 역할 | 색상 |
| --- | --- |
| 주요 행동·선택·링크 | `#D0442B` |
| 선택 배경 | `#FFF1EC` |
| 오류·확인 필요·보낼 돈 | `#B4235A` |
| 완료·예약 확정·받을 돈 | `#0B7A55` |
| 지연·임박 | `#A35F00` |
| 제목·본문·고정 일정 | `#191F28` |
| 보조 텍스트 | `#4E5968` |
| 화면 배경 | `#F2F4F6` |
| 카드·시트·입력 | `#FFFFFF` |

공통 색상은 `lib/core/theme/app_colors.dart`를 사용합니다.
일차별 핀 색은 행동 색상과 별개이며, 고정 일정은 검정 자물쇠로 구분합니다.
홈 커버는 PPT에 포함된 버건디·코랄·피치 그라데이션을 참고했습니다.

## 다음 화면 작업 시 확인할 부분

- PPT의 화면 ID와 설명을 함께 확인합니다. 기존 PDF는 보조 자료로 참고합니다.
- 기준 화면은 360×780dp이며 작은 화면에서는 스크롤로 대응합니다.
- 카드 모서리 20dp, 버튼·입력 모서리 14dp, 주요 버튼 높이 54dp를 기준으로 합니다.
- 공식 Pretendard v1.3.9의 400·500·600·700·800 굵기를 앱에 포함하고 `AppTheme.light`에서 공통 적용합니다.
- 경비 금액은 700 굵기와 동일 폭 숫자를 사용하며 좁은 화면에서는 부담액을 다음 줄로 배치하고, 긴 금액은 숫자가 중간에서 줄바꿈되지 않도록 전체를 축소합니다.
- 실제 앱과 Android Studio 위젯 미리보기는 같은 테마를 사용합니다. 글꼴 추가 후에는 앱을 완전히 종료하고 다시 빌드합니다.
- 글꼴 출처·해시는 `assets/fonts/README.md`, 라이선스는 `assets/fonts/OFL.txt`에서 확인합니다.
- 오류·완료·고정 상태는 색상과 아이콘·문구를 함께 사용합니다.
- 기존 홈·경비는 샘플이며, 인증·여행 화면은 서버 API를 호출합니다. 새 여행 화면 미리보기는 서버 없이 동작합니다. 결제·AI 호출은 연결하지 않았습니다.

## 일정 화면의 UX 기준

- 주요 행동은 화면 아래의 `일정 추가` / `일정 저장` 하나로 강조합니다. 버튼 높이는 54dp, 터치 영역은 최소 48dp로 둡니다.
- 날짜와 실제 월·일을 함께 표시하고 선택 상태를 배경·글자·스크린리더 정보로 전달합니다.
- 시간·제목·장소·예약 상태를 한 카드에 묶고, 고정·예약 상태는 아이콘과 문구를 함께 표시합니다.
- 예약 상태와 메모는 추가 옵션으로 펼쳐 필요한 입력부터 진행합니다.
- 날짜는 여행 기간 안에서만 선택하고, 종료 시간이 시작 시간보다 늦은지 확인합니다. 겹치는 일정은 확인 후 저장합니다.
- 입력을 버리거나 일정을 삭제할 때 확인합니다. 저장 오류가 나도 작성한 내용을 유지합니다.
- 동시 수정 충돌은 최신 내용을 먼저 확인한 뒤 사용자가 명시적으로 불러오도록 합니다.
- 작은 화면과 큰 글자에서는 시간 입력을 세로로 배치하며 날짜 목록과 본문은 스크롤할 수 있습니다.

근거: [Android 터치 영역](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views),
[Nielsen 사용성 원칙](https://www.nngroup.com/articles/ten-usability-heuristics/),
[점진적 공개](https://www.nngroup.com/articles/progressive-disclosure/).
이는 구현 기준이며 사용자 조사나 접근성 인증을 대체하지 않습니다.

## 정산 화면의 UX 기준

- 전체 지출과 내 정산 결과를 먼저 보여주고, 멤버별 상세는 눌러서 확인합니다.
- 받을 돈/보낼 돈은 초록/분홍과 문구·방향 아이콘을 함께 표시합니다. 차액 0은 추가 송금 없음으로 구분합니다.
- 내 송금과 전체 송금을 나눠 확인하며, 금액은 원 단위 정수 전체를 표시합니다.
- 조회 시각을 표시하고 새로고침 실패 시 이전 조회 결과라는 안내를 붙입니다.
- 지출 없음·차액 없음·내 송금 없음·내 멤버 정보 없음은 서로 다른 안내를 사용합니다.
- 큰 글자·작은 화면에서는 금액과 항목을 세로로 배치하며, 상세 내역도 스크롤할 수 있습니다.
- 샘플 미리보기와 서버 결과를 구분하고 실제 송금이 이루어진 것처럼 표시하지 않습니다.
