# 화면 디자인 기준

화면 구현 시 `5.StoryBoardUI설계서_Backpack_v1.1.pptx`를 기준으로 확인합니다.
기존 `Backpack_화면시안_v2_블루.pdf`와 색상이 다른 경우 PPT v1.1의 코랄 테마를 우선합니다.
원본 자료는 별도로 공유받으며, 개인 PC 경로는 저장하지 않습니다.

## 색상 (PPT 5쪽, BC-001)

| 역할 | 색상 |
| --- | --- |
| 주요 행동 (버튼 · 아이콘 · 선택 테두리 · 막대) | `#EE5E52` 코랄 |
| 코랄 글씨 (선택된 탭 · 링크 · 강조 문구) | `#BA3E33` |
| 선택 배경 | `#FFF2EF` |
| 오류·확인 필요·보낼 돈 | `#B4235A` |
| 완료·예약 확정·받을 돈 | `#0B7A55` |
| 지연·임박 | `#A35F00` |
| 제목·본문·고정 일정 | `#191F28` |
| 보조 텍스트 | `#4E5968` |
| 화면 배경 | `#F2F4F6` |
| 카드·시트·입력 | `#FFFFFF` |

주요 색은 PPT의 `#D0442B`(붉은 주황)를 더 밝은 코랄 `#EE5E52`로 바꿨습니다.
밝은 코랄은 흰 바탕에서 작은 글씨로 읽기 어려워(3.3:1), 작은 글씨에는 같은 계열의 진한 코랄 `#BA3E33`(5.5:1)을 씁니다.

공통 색상은 `lib/core/theme/app_colors.dart`를 사용합니다 (`AppColors.primary` 면 · 선, `AppColors.primaryText` 글씨).
일차별 핀 색은 행동 색상과 별개이며, 고정 일정은 검정 자물쇠로 구분합니다.
홈 커버는 PPT에 포함된 버건디·코랄·피치 그라데이션을 참고했습니다.

## 다음 화면 작업 시 확인할 부분

- PPT의 화면 ID와 설명을 함께 확인합니다. 기존 PDF는 보조 자료로 참고합니다.
- 기준 화면은 360×780dp이며 작은 화면에서는 스크롤로 대응합니다.
- 카드 모서리 20dp, 버튼·입력 모서리 14dp, 주요 버튼 높이 54dp를 기준으로 합니다.
- Pretendard가 지정되어 있으나 현재 앱에는 해당 글꼴 파일을 포함하지 않았습니다.
- 오류·완료·고정 상태는 색상과 아이콘·문구를 함께 사용합니다.
- 현재 앱은 프론트엔드 샘플이며 서버·결제·AI 호출은 연결하지 않았습니다.
